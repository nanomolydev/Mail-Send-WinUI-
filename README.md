# Mail Send

**Mail Send** — это десктопное приложение для Windows, разработанное на платформе WinUI 3. Оно предназначено для организации, выполнения и анализа массовых email-рассылок. Приложение предоставляет инструменты для управления SMTP-аккаунтами, списками получателей, шаблонами писем и отслеживания подробной статистики.

⚠️ **В настоящее время запуск невозможен — проект требует обновления и подключения серверной части.**

## Основные возможности

*   **Управление аккаунтами:** Добавление и хранение нескольких SMTP-аккаунтов для отправки писем.
*   **Списки рассылок:** Создание и редактирование списков email-адресов получателей.
*   **Шаблоны писем:** Конструктор шаблонов писем с поддержкой форматированного текста и файловых вложений.
*   **Гибкий процесс рассылки:** Возможность запуска, приостановки, возобновления и полной отмены процесса отправки.
*   **Многопоточность:** Поддержка многопоточной отправки для значительного ускорения рассылок (Pro-функция).
*   **Статистика и логи:** Визуализация статистики в виде графиков (по дням, неделям, месяцам) и ведение детального журнала всех операций.
*   **AI-помощник:** Интеграция с OpenAI API для автоматической генерации маркетинговых текстов и извлечения email-адресов из текста (Pro-функция, требует обновления).
*   **Импорт и экспорт:** Удобный импорт и экспорт данных (аккаунты, списки рассылки, шаблоны) в формате JSON.
*   **Настройка и локализация:** Гибкие настройки SMTP-сервера, логики рассылки и поддержка нескольких языков (Русский, Английский).

## Технологический стек

*   **Платформа:** Windows App SDK / WinUI 3
*   **Язык программирования:** C#
*   **База данных:** SQLite для локального хранения данных.
*   **Пользовательский интерфейс:** XAML, WinUIEx, Syncfusion Charts for WinUI.
*   **Работа с Email:** SMTP (System.Net.Mail).
*   **Ключевые библиотеки:**
    *   `Newtonsoft.Json` - для работы с форматом данных JSON.
    *   `WinUI3Localizer` - для локализации интерфейса.
    *   `OpenAI-API` - для интеграции с нейросетевыми моделями.
    *   `DeviceId` - для идентификации устройства.
    *   `PayPal.Api` - для обработки платежей.

## Описание функционала

### Управление аккаунтами (`account.xaml`)
Раздел позволяет добавлять и управлять SMTP-аккаунтами. Для каждого аккаунта можно указать email и пароль приложения. Приложение проверяет корректность данных, отправляя тестовое письмо. Поддерживается импорт/экспорт списка аккаунтов.

### Списки Email (`email.xaml`)
Здесь пользователи могут создавать и управлять списками получателей. Адреса можно добавлять вручную или вставлять из буфера обмена. Приложение также хранит историю завершенных рассылок (`past_emails.xaml`), которые можно просмотреть или использовать повторно.

### Шаблоны писем (`text.xaml`)
Этот раздел предназначен для создания и организации шаблонов писем. Каждый шаблон включает в себя тему, основной текст и возможность прикреплять файлы. Для удобства шаблоны можно группировать по папкам. Встроенный AI-помощник помогает генерировать привлекательные тексты для рассылок.

### Процесс рассылки (`home.xaml`)
Главный экран приложения, с которого запускается процесс отправки. После нажатия на кнопку "Старт" отображается индикатор прогресса, а также кнопки для управления процессом: пауза, возобновление и отмена. Алгоритм распределяет отправку писем между доступными аккаунтами и потоками согласно настройкам.

### Статистика (`statistic.xaml`)
Экран для анализа результатов рассылок.
*   **Графики:** Визуализируют количество успешно отправленных писем за выбранный период (день, неделя, месяц, год).
*   **Журнал (Логи):** Детальный список всех попыток отправки с указанием статуса (успешно/ошибка), адресата, времени и текста ошибки. Предусмотрена возможность фильтрации и копирования email-адресов.

### Настройки (`setting.xaml`)
Раздел для тонкой настройки приложения:
*   **Настройки SMTP:** Возможность использовать SMTP-сервер Google по умолчанию или указать адрес и порт собственного сервера.
*   **Многопоточность:** Слайдер для выбора количества одновременных потоков отправки.
*   **Логика рассылки:**
    *   **Автоматический режим:** Равномерно распределяет нагрузку между всеми активными аккаунтами.
    *   **Ручной режим:** Позволяет задать точный порядок и приоритет использования аккаунтов.
*   **Настройки приложения:** Выбор языка интерфейса, проверка обновлений и копирование ID устройства для Pro-активации.

## Установка и запуск

1.  Убедитесь, что у вас установлена Visual Studio 2022 с рабочими нагрузками "Разработка приложений для .NET Desktop" и "Разработка для универсальной платформы Windows", включая последнюю версию Windows App SDK.
2.  Откройте файл решения (`.sln`) в Visual Studio.
3.  Восстановите все зависимости NuGet.
4.  Соберите и запустите проект.

## Как использовать

1.  **Добавьте аккаунты:** Перейдите в раздел "Аккаунты" и добавьте хотя бы один рабочий SMTP-аккаунт.
2.  **Создайте шаблон:** В разделе "Тексты" создайте шаблон письма, указав тему, текст и, при необходимости, прикрепив файлы.
3.  **Сформируйте список получателей:** В разделе "Email" создайте список рассылки и добавьте в него email-адреса.
4.  **Настройте рассылку:** Перейдите в "Настройки", выберите режим рассылки (автоматический/ручной) и количество потоков.
5.  **Запустите процесс:** Вернитесь на главный экран и нажмите кнопку "Старт".
6.  **Анализируйте результаты:** Отслеживайте прогресс на главном экране и просматривайте детальные отчеты в разделе "Статистика".
