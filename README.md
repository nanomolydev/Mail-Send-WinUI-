# Mail-Send-WinUI-

## Обзор
**Mail-Send-WinUI-** — десктопное приложение на **WinUI 3**, предназначенное для массовой рассылки писем с использованием нескольких учётных записей и потоков.  
Проект построен по шаблону **MVVM** и использует **Newtonsoft.Json** для сериализации данных.

> ⚠️ В настоящее время запуск невозможен — проект требует обновления и подключения серверной части.

---

## Особенности

- **Алгоритм распределения получателей**  
  Класс `Algorithm.cs` реализует логику равномерного распределения адресатов между доступными аккаунтами и потоками, учитывая их количество и загруженность.

- **Многопоточная рассылка**  
  Метод `generate_thread` делит задачи по потокам, чтобы добиться равномерной нагрузки и ускорить отправку.

- **Статистика и аналитика**  
  Приложение собирает статистику: количество отправленных сообщений, процент доставленных и прочитанных писем.  
  Данные визуализируются в графиках с возможностью переключения периода (день, месяц, год).

- **Фильтрация и сортировка**  
  Возможна сортировка по отправителям, дате и статусу доставки.

- **Режимы настройки**  
  Пользователь может выбрать автоматическую или ручную конфигурацию параметров рассылки (потоки, аккаунты, тайминги).

- **Сохранение конфигураций**  
  Настройки кампаний сохраняются в JSON и могут быть восстановлены при следующем запуске.

- **Современный интерфейс**  
  WinUI 3 обеспечивает современную визуальную оболочку; проект следует структуре MVVM — папки `Activation`, `Behaviors`, `Converters`, `Services`, `ViewModels`, `Views`.

## Установка

1. Установите **Visual Studio 2022** с рабочими нагрузками:
   - «Разработка классических приложений .NET»
   - **WinUI 3** (через пакет **Windows App SDK**)
2. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/yadegenn/Mail-Send-WinUI-.git

3. Откройте решение `Mail Send.sln`.
4. Восстановите NuGet-пакеты и соберите проект **Mail Send** под платформу x64 или x86.

---

## Использование

1. Добавьте почтовые аккаунты.
2. Импортируйте или введите список адресатов — приложение распределит их по аккаунтам и потокам.
3. Укажите тему, текст и количество потоков.
4. Запустите рассылку — система отобразит прогресс и статистику в реальном времени.
